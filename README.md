# 推しごとカレンダー

**推しごと**＝「推し事」と「推し毎」。
推しを追いかけるのは、もはやお仕事です。そのお仕事を、推しごとにまるっと引き受けます。

自分の予定と推しのスケジュールを、ひとつのカレンダーに並べて見るためのアプリです。
「バイトの日にライブが重なってた」を防ぐのが目的です。

## 使う

### 👉 https://takashi33.github.io/oshigoto-calendar/

スマホのブラウザで開いて、**ホーム画面に追加**すると、アプリのように使えます。

- **iPhone**（Safari）… 共有ボタン（□に↑）→「ホーム画面に追加」
- **Android**（Chrome）… 右上の「⋮」→「ホーム画面に追加」

追加すると、**圏外でも開けます。**

## できること

- **自分の予定と推しの予定が同じカレンダーに並ぶ**（自分はグレー、推しは推しの色）
- 推しは何人でも登録できて、**写真や絵文字をアイコンに設定できる**
- **締切**（チケットの申込・当落・入金）を別枠で管理。3日を切ると赤くなる
- 公式のお知らせを**貼り付けると、日にちを見つけて予定の候補にする**
- ほかのアプリの「共有」から送ると、貼り付け済みの状態で開く
- 毎日・毎週の繰り返し。1回だけ休みにもできる
- 使ったお金の集計と、今年のふりかえり
- 日本の祝日を表示
- スマホのカレンダー（iPhone / Google）へ**予定を書き出せる**（通知もそちらで鳴る）

## データの置き場所

**入れた予定は、あなたのスマホの中だけに保存されます。**
どこかのサーバーへ送ることはありません。ログインも不要です。

そのぶん、スマホを買い替えたりブラウザのデータを消したりすると消えてしまいます。
アプリの ⚙️ から**控えを取っておく**と、あとから元に戻せます。

## 作り

外部のライブラリやサービスを使わない、1枚のHTMLです。

| ファイル | 中身 |
|---|---|
| `index.html` | 本体（CSS・JavaScriptを内包） |
| `sw.js` | オフラインで開くための Service Worker |
| `manifest.webmanifest` | ホーム画面に追加するための定義 |
| `test.js` | 自動テスト（`node test.js`） |
| `deploy.sh` | GitHub Pages への公開 |

⚠️ `index.html` を更新したら `sw.js` の `CACHE` の版数も上げること。
上げないと、利用者の端末に古い画面が残り続けます（`deploy.sh` が検出して止めます）。
